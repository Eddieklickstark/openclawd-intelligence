# Quick Deploy Guide

## Option 1: Vercel CLI (Empfohlen)

```bash
cd openclawd-ultimate
npm install
npm run build
npx vercel --prod
```

## Option 2: Vercel Dashboard

1. Gehe zu https://vercel.com/new
2. "Upload" wählen
3. Den `dist` Ordner hochladen
4. Done!

## Option 3: GitHub

1. Push zu GitHub
2. Vercel verbinden
3. Auto-deploy!
